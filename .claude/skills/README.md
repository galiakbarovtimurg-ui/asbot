# Скиллы для Claude

Сюда кладутся скиллы — инструкции для Claude под конкретные задачи.
Они работают во всех чатах Claude Code, где открыт этот репозиторий.

## Как добавить скилл

Каждый скилл — отдельная папка с файлом `SKILL.md`:

```
.claude/skills/
└── имя-скилла/
    └── SKILL.md
```

Начало файла `SKILL.md`:

```
---
name: имя-скилла
description: Когда Claude должен использовать этот скилл (одно-два предложения).
---

Дальше — сама инструкция обычным текстом.
```

## Важно

Репозиторий публичный — не кладите сюда пароли, ключи и данные клиентов.
